# registro-promedio-ucv
App web para llevar un recuento de de las calificaciones y calcular tu promedio semestral, anual y general dependiendo de tu carrera y la malla correspondiente. Se guarda todo localmente en el navegador del cliente (esta versión no tiene base de datos), permite importar y exportar los datos en caso de pérdida repentina. Sujeto a mejoras. vibecoding
